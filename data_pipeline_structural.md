# Data Pipeline 
```
build_panel.py
  │
  ├─ data.py                 builds a daily panel for each firm
  │                          (market cap E, default point D, risk-free rate r)
  │
  ├─ builds two tables       (in memory only, not saved)
  │     obs           one row per firm-month: firm, date, D, r, label y
  │     daily_equity  daily market cap for every firm (dates x firms)
  │
  ├─ merton.py               compute_structural_features(obs, daily_equity)
  │                          <-- the Merton model: DD, PD, ln V_A, sigma_A, D/V_A
  │
  └─ writes panel.csv        obs + structural features
        │
        ▼
  ML / sequence / hybrid models
```

### data.py:
a point-in-time layer that takes debt and share counts from SEC filings only after their filing date, adjusts shares for stock splits, and uses prices that are not dividend-adjusted.
### edgar_labels.py:
builds bankruptcy labels from 8-K Item 1.03 filings in the SEC bulk files, checks fundamentals and price coverage for each bankrupt firm, and samples control firms. The control sample must exclude every CIK in the full `bankruptcies.csv` event table, not just firms that pass fundamentals coverage.
### build_panel.py:
produces the labelled firm-month panel (panel.csv) with 12-month-ahead labels and structural features, with post-filing rows removed. It screens controls against the full event table and saves per-firm collection failures to `panel_build_failures.csv`.
### merton.py:
Each firm-date yields DD, PD, ln V_A, σ_A and D/V_A, with status codes that flag bad inputs instead of failing silently. The sensitivity-grid parameters (volatility window, horizon, tolerance, debt definition) are exposed for the RQ3 analysis.
## Data files: Pipeline outputs generated by the code:
### bankruptcies.csv (from edgar_labels.py labels):
#### one row per bankrupt non-financial firm, built from SEC 8-K Item 1.03 filings from 2010 onward.
Identity: cik, name, sic, entity_type, tickers, exchanges.
Label dates: bankruptcy_date (the date of the firm’s first Item 1.03 event), first_filing_date, n_1_03_filings, first_accession.
Fundamentals coverage: fund_status (ok, no_xbrl, no_debt, no_shares or stale), n_fund_before (number of fiscal years of debt data filed before the bankruptcy), debt_age_days (age of the latest fundamentals at the bankruptcy date).
It is the master list of failed firms, including the ones we later lose.
### bankruptcies_covered.csv (from edgar_labels.py prices):
#### the subset of bankruptcies.csv with usable fundamentals (fund_status == ok), plus price-availability checks.
Extra columns: ticker used for prices, price_status (ok, no_ticker, no_prices, ends_too_early or too_few_label_months), n_label_months (how many of the 12 label months have 252+ prior trading days), first_price, last_price.
Only rows with price_status == ok go into the panel. The status counts are the coverage report.
controls.csv (from edgar_labels.py controls): a random sample of healthy comparison firms.
Columns: cik, ticker, name, sic.
Drawn from the SEC’s current ticker list with financials excluded, so they are survivors by construction, and they are a sample (so predicted PDs need the prior_correct adjustment). The original saved controls overlap the full EDGAR event inventory; the current panel builder removes all such firms before a future rebuild.
### panel.csv (from build_panel.py): 
#### the main modelling dataset, one row per firm per month-end, with 42 columns. The corrected packaged panel produced 57,749 rows from 27 event firms and 572 controls, with 186 positive months across 17 firms.
Keys and label: firm (CIK), date, y (1 if bankruptcy falls within the next 12 months), bankrupt_firm (1 if the firm ever failed).
Model inputs: D (default point), r (risk-free rate), E (market cap), sigma_E (equity volatility), plus data-quality flags debt_age_days and debt_partial.
Structural features for each of the four variants (kmv, simul_mu_r, simul_mu_hist, naive): _dd, _pd, _ln_va, _sigma_a, _d_va, _va, _mu and _status.
The corrected status counts for kmv are 52,882 ok, 4,673 invalid input and 194 insufficient history. Every positive month is status 0 for KMV; the first tree smoke run can use core features without waiting for a structural-feature diagnosis. The source panel’s event flag disagreed with the full event table on 617 firm-month rows; the packaging step removed 608 post-event rows and recomputed the event flag. Ten event firms are right-censored beyond the panel’s final date and therefore have no positive months.
The source panel was supplied from Downloads and is not present in the repository. Raw SEC bulk archives are also not present, so the current artifact is reproducible from the listed local CSVs but a fresh EDGAR extraction is not.
